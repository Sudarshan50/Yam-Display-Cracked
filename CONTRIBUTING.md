# Contributing to Yam Display

Thank you for your interest in contributing to this project! This repository serves as an archival/preserved version of Yam Display for educational purposes.

## How to Contribute

### Reporting Issues

If you encounter problems:
1. Check existing issues first
2. Create a new issue with:
   - Clear description of the problem
   - Steps to reproduce
   - iOS version and device model
   - Installation method used

### Documentation Improvements

We welcome improvements to:
- README.md clarity and accuracy
- INSTALLATION.md steps and troubleshooting
- Adding translations
- Fixing typos or broken links

### Code Contributions

Since this is a preserved binary:
- We don't accept modifications to the IPA itself
- Documentation and tooling improvements are welcome
- Scripts for automation are appreciated

## Pull Request Process

1. Fork the repository
2. Create a feature branch (`git checkout -b feature/improvement`)
3. Make your changes
4. Commit with clear messages
5. Push to your fork
6. Open a Pull Request with description

## Code of Conduct

- Be respectful and constructive
- Focus on educational value
- Respect intellectual property
- No malicious modifications

## Questions?

Open an issue for discussion before major changes.

Thank you for contributing!
