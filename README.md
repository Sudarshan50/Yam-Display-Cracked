## 📱 About

Yam Display transforms your iPad into a wireless second display for your computer. This is a decrypted version of the Yam Display Free app (version 1.2.1) for educational and research purposes.

## ✨ Features

- 🖥️ **Wireless Display Extension** - Use your iPad as a second monitor
- 🔄 **Multi-Orientation Support** - Portrait and landscape modes on iPad
- 🌐 **Multi-Language Support** - Available in English, French, Japanese, and Korean
- 📱 **Universal App** - Supports both iPhone and iPad devices
- 🎯 **Peer-to-Peer Connection** - Direct device-to-device connectivity

## 📋 Requirements

- iOS 9.0 or later
- iPad (recommended) or iPhone
- Jailbroken device OR AltStore/Sideloadly for installation
- Compatible computer with Yam Display server software

## 📦 Installation

### Method 1: Using AltStore (Recommended)
1. Install [AltStore](https://altstore.io/) on your device
2. Download the `YamDisplay_Cracked.ipa` file from the [Releases](../../releases) page
3. Open AltStore on your device
4. Tap the "+" icon and select the downloaded IPA file
5. Wait for installation to complete

### Method 2: Using Sideloadly
1. Download [Sideloadly](https://sideloadly.io/)
2. Download the `YamDisplay_Cracked.ipa` file
3. Connect your device to your computer
4. Open Sideloadly and drag the IPA file
5. Enter your Apple ID and click Start

### Method 3: Jailbroken Devices
1. Download the IPA file
2. Use Filza or similar file manager
3. Install directly via AppSync Unified

For detailed installation instructions, see [INSTALLATION.md](INSTALLATION.md)

## 🚀 Usage

1. Launch Yam Display on your iPad
2. Install Yam Display server software on your computer
3. Ensure both devices are on the same network
4. Connect from the iPad app to your computer
5. Your iPad is now a second display!

## 🔧 Troubleshooting

### App Won't Install
- Ensure your device is running iOS 9.0 or later
- Try deleting any previous versions
- Check if you have enough storage space
- Verify the IPA file downloaded completely

### Connection Issues
- Ensure both devices are on the same WiFi network
- Check firewall settings on your computer
- Restart both the app and server software
- Try disabling VPN if active

### App Crashes
- Clear app cache via Settings
- Reinstall the application
- Check iOS version compatibility
- Review device logs for errors
